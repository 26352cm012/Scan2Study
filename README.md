# 📚 Scan2Study

Scan2Study is an educational app designed to turn scanned study material into organized learning resources.

## 🚀 Planned Features

- 📸 Scan study material
- 📝 Extract text using OCR
- ✨ Generate summaries
- 🧠 Create practice questions
- 📖 Organize study material
- 🔍 Ask questions about your notes

## 🛠️ Technology

- Python
- OCR
- Computer Vision
- AI/NLP

## 📌 Project Status

Early prototype — actively developing.
